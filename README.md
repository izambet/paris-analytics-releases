# Versions publiées (mises à jour automatiques)

Ce dépôt ne contient **que** les installateurs Windows publiés et leurs métadonnées de mise à jour
(`latest.yml`, `.blockmap`), dans l'onglet **Releases**. L'application installée y vérifie
automatiquement au lancement puis toutes les 4 heures s'il existe une nouvelle version,
la télécharge en arrière-plan et l'installe au redémarrage.

- Aucun code source, aucune donnée, aucune clé ni aucun secret n'est stocké ici.
- Installation : télécharger le dernier `…-Setup-x.y.z.exe` dans Releases et l'ouvrir
  (installation pour l'utilisateur courant, sans droits administrateur).
